TG Ledger 4.4.0 — как запустить активацию без длинных команд

1. Дважды щёлкните START_ACTIVATION.cmd. Нужен Python 3 с tkinter.
   При необходимости менеджер предложит установить cryptography.
2. Если прежний developer_private_key.pem сохранился — «Импорт прежнего .pem».
   Если ключ потерян — явно «Создать новый ключ». Старый ключ молча не заменяется.
3. Менеджер автоматически настраивает публичный ключ проекта.
   Нажмите «Собрать APK с этим ключом» или «Собрать и установить по USB».
   Для сборки нужны Android SDK/JDK; для установки — телефон с USB debugging.
4. В приложении: Настройки → Активация TG Plus → «Скопировать запрос активации».
5. Вставьте полный TGREQ1-запрос в менеджер, укажите дни → «Выдать код».
   «Скопировать только код» → вставить в приложение → активировать.

Ключ хранится в %USERPROFILE%\.tg-ledger\activation\, а не внутри папки версии.
В следующей версии нажмите «Настроить проект» — используется тот же ключ.
Сохраните защищённую резервную копию вне папки проекта. Не присылайте приватный ключ.

Новый ключ не может работать со старым APK: нужно один раз собрать и установить
APK с новым публичным ключом. Обновление поверх требует прежнюю подпись APK
(она не является activation .pem). Не удаляйте приложение при ошибке подписи.

Архив содержит исходный проект, не готовый персонально настроенный APK.
Подробно: docs/ACTIVATION_4.4.0_RU.md.
