## Ключи и выдача без сборки

Публичный ключ извлечён из фактического DEX и совпадает с конфигурацией личного генератора. Личная пара вне репозитория проверена: тестовый 5-дневный TG2-код подписан и проверен публичным ключом поставки. Это не запуск личного Windows EXE с production-ключом в CI: Windows GUI использует временную тестовую пару.

Личный ZIP содержит готовый EXE, согласованный private-файл, issuer-config и резервную копию подписи APK. CRC архива проверен. Он передаётся владельцу приватно, не входит в GitHub/source ZIP/CI. Для выдачи не нужны Python/Gradle/SDK/Android Studio. Срок начинается при выдаче; 0 дней означает бессрочно.

## Ограничения

- Телефон пользователя, его старый APK/signing keystore и реальные банковские счета не проверялись. Конфликт старой подписи нельзя обходить удалением данных. Старый debug package может установиться рядом, данные/разрешения не мигрируют автоматически.
- Новый activation-ключ не делает старые коды автоматически действительными. ID/request берутся из нового APK.
- Exact release smoke доказывает установку/старт, не всю цепочку активации на физическом телефоне. Crypto/пersistence проверены отдельными unit/native тестами.
- API банков, push, Plus и функции 4.4.0 сохранены; универсальное API всех банков не заявляется. Удалённые из шторки уведомления Android не предоставляет; после force-stop нужен запуск приложения.
- Исторические отчёты 4.4.0 и старше не переименованы в новые результаты.
