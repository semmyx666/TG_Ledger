# Проверка крупного релиза 4.3.3

Номер приложения — 4.3.3; Android versionCode — 18. Релиз сохраняет API monobank и Автоклиента ПриватБанка для бизнеса/ФОП, новый push-импорт, ограничения периодов и адаптивный интерфейс.

Новый CI запущен. Итоги будут добавлены после завершения сборок, unit, lint и тестов Android 8/16. Историческое подтверждение предыдущей кодовой базы не переименовывается и находится в `history/3.3.3/`.
