## Активация: проверенная цепочка

- Импорт прежнего RSA-ключа без изменения исходного файла; явное первое создание 3072-битной пары; запрет молчаливой замены отличающегося стабильного ключа.
- Хранилище вне папки версии; настройка следующей распакованной версии тем же ключом.
- Пробелы/кириллица в Windows-пути, в том числе перенаправленная ASCII-консоль. Исправлен найденный отказ кодировки после импорта.
- Локальная публичная настройка имеет приоритет над устаревшей Gradle-настройкой; неправильная или обязательная отсутствующая настройка отвергается сборкой. Отсутствующий необязательный ключ явно показан в приложении, а не заменён примером.
- `TGREQ1` сверяет ожидаемый ключ приложения до выдачи; подпись `TG2`, продукт, устройство, дата и срок проверяются отдельно.
- Реальный публичный тест-вектор, подписанный Python, принят Kotlin-проверкой для v1 и v2. Приватный ключ вектора не сохранён и не входит в проект.
- Настоящий Android Keystore: переносы строк в коде → успешная активация → зашифрованное хранение → новый экземпляр репозитория → доступ восстановлен.
- Неверный код не отнимает действующий доступ; старый короткий код не сокращает бессрочный. Отказ сохраняет ввод; повторное нажатие во время проверки игнорируется.
- Узкий экран 320 dp и шрифт 140%: обнаружено и исправлено переполнение Key ID на Android 16; ID переносится группами, запрос копируется без визуальных пробелов. Сообщения и кнопки доступны прокруткой. Снимки двух Android-версий получены из финального прогона, не из макета.
- Текст больше не обещает бессрочную активацию для временного кода.

## Границы проверки

- Не проверены телефон пользователя, его конкретный .pem, APK signing keystore, установленные APK и банковские счета. Пользовательский приватный ключ не запрашивался и не использовался.
- Windows GUI smoke — автоматический тест реального Tk-окна и clipboard, не ручной тест на ПК пользователя.
- В исходном архиве нет готового персонально настроенного APK и общего приватного ключа. Менеджер создаёт/импортирует пару локально, настраивает публичный ключ и запускает сборку. Для сборки/USB-установки нужны SDK/JDK и подключённое устройство; нужна прежняя подпись APK для обновления поверх.
- Новый ключ требует обновить публичный ключ установленного APK; потерянный приватный ключ не восстанавливается из публичного. Новая пара не делает действительными коды, подписанные старой парой.
- Банковские API проверены mock-ответами, не настоящими аккаунтами. Android не отдаёт удалённые push; после force-stop нужно открыть приложение. Универсальный API всех банков не реализован.
