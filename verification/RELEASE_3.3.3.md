### Проверки банков

- Реальное уведомление от отдельного установленного QA-приложения → системный NotificationListenerService → запись в Room, без открытого Activity.
- Точный повтор, сообщение двухминутной давности в шторке после выдачи доступа, InboxStyle с двумя платежами, MessagingStyle и переключение обратно в push при подключённом listener.
- Другая похожая покупка сохраняется на проверку, не удаляется молча.
- Бесплатный доступ, активный trial и потеря Premium: длительный запрос возвращается к сегодня до получения статистики.
- monobank / Автоклиент: ответы mock-сервера, копейки без float, статус проведённой операции, пагинация, повтор cursor, ошибка доступа.

### Нативный интерфейс

288 / 320 / 360 dp; шрифт до 170%. Тесты проверяют отсутствие обрезания суммы/кнопки, реальные разные X-координаты трёх показателей при 360 dp, перенос длинной категории по словам и открытие Premium при нажатии закрытого периода. Реальные снимки визуально просмотрены и сохранены в `verification/screenshots/`. Полные device-отчёты — `verification/device-reports/`.

После указанного прогона в пакет добавлены только документация, отчёты, снимки, экспорт исходников и контрольные суммы. Рабочий код не изменялся.

## Не проверено / ограничения

- Настоящие токены и счета пользователя; API-тесты используют mock-сервер, не подтверждают работу конкретного банковского аккаунта.
- Физический телефон пользователя, ограничения его производителя и все версии push всех банков.
- Android не предоставляет этому listener историю уже удалённых уведомлений. После force-stop нужно снова открыть приложение.
- ПриватБанк API реализован для Автоклиента бизнеса / ФОП, не для обычной розничной карты Приват24. Другие банковские API требуют отдельного документированного/авторизованного подключения.
