# Нативные снимки 4.4.0

Снимки получены из реально выполненных Compose/Android instrumentation tests, не из HTML-макета и не из генератора изображений.

- `activation-320dp-font140-uk.png`: экран активации, Key ID и конкретная причина отказа, шрифт 140%. ID/Key ID — синтетические тестовые данные.
- `compact-288dp-uk.png`: компактный итог, узкий экран.
- `compact-320dp-font170-uk.png`: итог и кнопка восстановления при системном шрифте 170%.
- `compact-360dp-uk.png`: три показателя горизонтально; тест проверяет их разные X-координаты, а снимок имеет настоящую ширину 360 px при density 160.
- `bank-320dp-font140-uk.png`: настоящий BankScreen с украинскими подписями, шириной 320 dp и шрифтом 140%.
- `category-320dp-font140-uk.png`: длинное название категории; переносится по словам, а сумма располагается отдельно, если строка не вмещает оба текста.

Числа — тестовые операции, не данные реального банковского счёта. В компонентных тестах украинские подписи проверяются также с денежным форматом EN/UAH, чтобы длинный префикс валюты не обрезался. В работающем приложении формат суммы выбирается по языку пользователя.

Каталог содержит варианты Android 8 (API 26) и Android 16 (API 36). Область захвата компонента может быть меньше всего экрана.
