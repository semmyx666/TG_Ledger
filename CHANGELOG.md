# История релизов TG Ledger

## 4.3.3 — крупный релиз банковского импорта и адаптивного интерфейса

### API сохранено и расширено

- **monobank personal API не удалено**: токен, чтение счетов/выписки, периодическая синхронизация и запуск вручную.
- **ПриватБанк Автоклиент**: read-only выписка для бизнеса/ФОП, пагинация и идентификаторы проведённых операций. Это не API обычных розничных карт Приват24.
- Токены хранятся через Android Keystore; приложение не создаёт и не авторизует банковские платежи.
- Push, API и SMS остаются отдельными выбираемыми способами. Push — начальный выбор для новых установок, **не замена и не удаление API**.

### Банковские push без SMS и без токена

- Фоновый NotificationListenerService сохраняет однозначные операции без открытого экрана приложения.
- Разбор обычных, развёрнутых, InboxStyle и MessagingStyle уведомлений; несколько платежей не смешиваются в одну сумму.
- Повторное чтение банковских уведомлений, оставшихся в шторке, после подключения/переподключения и возвращения в push-режим.
- Точный повтор не создаёт вторую запись. Похожая отдельная покупка остаётся в очереди проверки, а не удаляется молча.
- OTP, отказы и сообщения только с балансом не создают расход.

### Plus и периоды

- В банках без Plus/активного trial — сегодня; с доступом — 7 дней, 30 дней и вся история.
- Проверка стоит перед запросом статистики. Потеря доступа возвращает окно к сегодняшнему дню.
- 30 дней — скользящий период, не начало календарного месяца. Сбор операций не прекращается из-за фильтра отображения.

### Компактный адаптивный интерфейс

- Баланс, доходы и расходы — одна карточка вместо нескольких больших блоков.
- На широком телефоне — три выровненных показателя; на узком экране/крупном шрифте — читаемая вертикальная структура.
- Помощник уменьшен, банковские настройки свёрнуты.
- Восстановление покупок — отдельная кнопка полной ширины.
- Название банка/категории и сумма перестраиваются по реально измеренной ширине текста; названия не сжимаются до фрагментов слова.

### Справка, системные файлы и проверка

- В справке приложения добавлен заметный блок «Що нового у 4.3.3» с перечислением крупных изменений и явным указанием, что API сохранено.
- Дописаны инструкции по банкам, разрешениям, фону, API и обновлению с сохранением ключей.
- `versionName=4.3.3`, `versionCode=18`; обновлён API User-Agent, README, документация, исходный сборник, дерево проекта и SHA-256 manifest.
- `applicationId`, схема Room и ключи пользователя не меняются из-за переименования релиза.
- CI: play/legacyV7 debug, play release с R8, unit, lint и реальные инструментальные тесты Android 8/16.
- Отдельное QA-приложение публикует настоящие Android push; оно не входит в APK TG Ledger. Нативные снимки и отчёты входят в исходный пакет.

### Честные границы

Android не отдаёт приложению историю уже удалённых уведомлений; после force-stop нужно открыть его снова. Универсального API всех банков не реализовано. API-тесты используют mock-серверы; настоящие счета и телефон пользователя в разработке не используются.
