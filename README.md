# TG Ledger 3.3.2 — API/SMS для банків, пробний період, кіт, «картка чи готівка»

- **Версія**: `versionName=3.3.2`, `versionCode=16`.
- **Банки — два способи** (екран Банки → «Спосіб імпорту»): **API-ключ monobank** (токен з api.monobank.ua, зберігається зашифрованим у Keystore, читання виписки кожні ~15 хв і за кнопкою) та **SMS** (дозвіл на SMS є в обох збірках, кнопка «Сканувати SMS за 30 днів» показує, скільки знайдено/додано). Режим «Сповіщення» лишився як резервний.
- **Пробний період**: єдині 14 днів стартують самі при першому запуску (без кнопки, без картки, без автосписання).
- **Кіт** завжди на головному екрані: з Premium/пробним — працює, без нього — заблокований і веде до Premium; помічник увімкнено за замовчуванням.
- **«Картка чи готівка»**: у формі ручного додавання обов'язковий вибір; кіт при голосовому/текстовому додаванні питає (діалог + голос), якщо ви самі не сказали «карткою/готівкою».

# TG Ledger 3.2.0 — Преміум дизайн та крос-банкова дедублікація

Масштабне оновлення логіки фонового імпорту банківських транзакцій та зовнішнього вигляду додатку.
- **Cross-Source Deduplication**: Новий дворівневий алгоритм (Tier 1: ±90с для того ж банку, Tier 2: ±180с для однакових транзакцій з різних джерел, наприклад Privat24 та Google Pay). Зберігається `groupKey` у базі (Room DB Migration `v2 -> v3`).
- **Background Processing**: `BankNotificationListener` переведено на стабільний `CoroutineScope` всередині `LedgerApplication`. Додано системні Notification (Android 13+ `POST_NOTIFICATIONS`) при успішному автоімпорті у фоні.
- **Premium UI & UX**: Оновлено `Theme.kt` (Pure OLED Black для Dark Mode, тепліші кольори для Light Mode). Збільшено `lineHeight` для уникнення обрізання тексту. Усі картки транзакцій та балансу (`DashboardScreen.kt`, `BankScreen.kt`) переверстано з використанням суворих `Modifier.weight()` та `TextOverflow.Ellipsis`, щоб текст ніколи не виходив за межі екрану. Додано спеціальний чіп для статусу `CROSS_DUPLICATE_REVIEW`.
- `versionName=3.2.0`, `versionCode=13`.
