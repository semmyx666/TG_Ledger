# Банки и компактный интерфейс — 4.4.0

## Что изменено

- В банках бесплатный период — **сегодня**. Активный TG Plus / 14-дневный пробный период открывает последние 7 дней, последние 30 дней и всю историю. Проверка стоит **перед запросами данных** в BankViewModel, а не только на кнопках. При потере подписки запрос возвращается к сегодняшнему дню. «30 дней» теперь действительно скользящие 30 дней, не начало календарного месяца.
- Сбор операций не ограничен этим фильтром: ограничивается отображаемая банковская статистика. Ручной журнал и экспорт сохранены.
- Основной режим новых установок — **Push банка**, не SMS. Ранее явно выбранный пользователем способ не перезаписывается.
- Сервис обрабатывает обычные уведомления, BigText, InboxStyle и MessagingStyle. Несколько платежей в InboxStyle разбираются по отдельным строкам, не как одна неоднозначная сумма.
- Подключение/переподключение читает уведомления, которые **ещё видны в шторке**. Повторное чтение доступно также при возвращении из другого режима в push, даже если сервис уже подключён.
- Собственные уведомления TG Ledger, OTP, отказы и сообщения только с балансом не создают операцию. Неоднозначные сообщения и переводы идут на проверку.
- Повтор одного события не создаёт вторую запись. **Другая операция с той же суммой/магазином не удаляется молча**: она сохраняется как возможный дубль в очереди. Банковское API использует идентификаторы операций, а не эвристику близких сумм.
- Подтверждение импорта отправляется только **после** успешной транзакции Room. Отсутствие разрешения на собственные уведомления не отменяет сохранение.
- Главный экран: баланс, доход и расход в одной карточке; при узком экране/крупном системном шрифте показатели переходят на отдельные строки. Банковские настройки свёрнуты. Длинное название банка/категории переносится над суммой, когда измеренный текст не помещается в строку; слова не сжимаются до фрагментов. Восстановление покупок — отдельная кнопка полной ширины; действия синхронизации переходят на следующую строку вместо сжатия до отдельных букв.
- В справке приложения добавлен полноценный раздел про банки, доступ, фон, подписку и API.

## Настройка push

1. Банки → **Налаштування імпорту** → **Push банку (рекомендовано)**.
2. Включить импорт и автоимпорт, предоставить доступ к уведомлениям Android.
3. Разрешить работу в фоне в настройках батареи. Для приложений, установленных из файла, Android может сначала требовать разрешить ограниченные настройки.
4. В банке включить push о расходных операциях с видимой суммой. Если банк скрывает содержимое, приложение не может извлечь то, что Android не передаёт.
5. При необходимости включить отдельное разрешение TG Ledger на подтверждения сохранения.
6. Если приложение банка не определяется, настроить его точный Android package в «Застосунки банків». Для отсутствующего банка — **Інший банк / Other bank**. Это разрешает чтение только выбранного приложения, не всех уведомлений подряд.

### Ограничения Android

- Доступ к уведомлениям **не предоставляет историю уже убранных push**. Восстановить их без API нельзя.
- После **«Принудительно остановить»** нужно снова открыть TG Ledger. Обычное закрытие экрана не равно force-stop.
- Ограничения батареи производителей могут задержать/остановить сервис; универсальная гарантия работы на любом телефоне невозможна.
- Раз в ~15 минут WorkManager пытается восстановить сервис; это минимальный период, **не точное расписание**. Живой подключённый listener обрабатывает push при поступлении, без ожидания этого воркера.
- Уведомления не являются заверенной выпиской банка. Неизвестные/изменённые форматы требуют обезличенного примера для отдельного теста.

## API

### monobank — личный токен

Поддержан существующий personal API: https://api.monobank.ua/docs/ . Токен вводится в приложении и шифруется Android Keystore. Запросы только к API monobank, только чтение счетов/выписки. Первое чтение — 30 дней, последующие — периодически и по кнопке. Перенаправления отключены, чтобы не пересылать токен на другой хост.

### ПриватБанк — Автоклиент, бизнес / ФОП

**Это не API обычной личной карточки Приват24.** Нужен счёт Приват24 для бизнеса / ФОП и действующий токен Автоклиента. В его настройках следует оставить только право получать балансы и транзакции.

- Официальная инструкция: https://privatbank.ua/business/intehratsiya
- Документация, на которую ссылается банк: https://docs.google.com/document/d/e/2PACX-1vTtKvGa3P4E-lDqLg3bHRF6Wi9S7GIjSMFEFxII5qQZBGxuTXs25hQNiUU1hMZQhOyx6BNvIZ1bVKSr/pub
- Используется только `GET https://acp.privatbank.ua/api/statements/transactions`.
- Обработаны пагинация `followId`, направление D/C, сумма в копейках, статус проведённой реальной операции, дата в зоне Europe/Kyiv и уникальность счёт + REF + REFN.
- Токен не записывается в логи/исходники, хранится в Keystore, не пересылается при redirect. Создание/авторизация платежей не реализованы.
- Первый импорт разбит на короткие окна, всего последние 30 дней. После него запрашиваются изменения с перекрытием для поздно проведённых операций.

### Другие банки

Нет универсального личного API-ключа для всех банков. Open Banking требует авторизованного поставщика, банковского протокола согласия и соответствующих разрешений. Поле произвольного URL/ключа не сделало бы интеграцию работающей и могло бы раскрыть банковские данные. Поэтому для остальных банков добавляется точный package приложения и используется push; отдельный API-адаптер возможен по документированному протоколу и доступу банка.

## Как воспроизвести тесты

CI: `.github/workflows/android.yml`. JDK 17, SDK 36. На эмуляторах Android 8 (API 26) и Android 16 (API 36) ставится отдельное тестовое приложение `bank-fixture`, которое публикует настоящие Android-уведомления от другого package. Оно **не входит в APK TG Ledger**.

```bash
./gradlew :bank-fixture:assembleDebug
adb install -r bank-fixture/build/outputs/apk/debug/bank-fixture-debug.apk
# Для Android 13+:
adb shell pm grant com.semmyx.ledger.bankfixture android.permission.POST_NOTIFICATIONS
./gradlew :domain:test :data:testPlayDebugUnitTest :app:testPlayDebugUnitTest
./gradlew :data:connectedPlayDebugAndroidTest :app:connectedPlayDebugAndroidTest
```

Проверки: запись push без Activity, точный повтор, восстановление сообщения двухминутной давности после выдачи доступа, InboxStyle с двумя платежами, MessagingStyle, переключение режима при подключённом listener, сохранение спорной равной суммы для проверки, бесплатный/пробный/истёкший доступ, пагинация API и адаптивные компоненты 288/320/360 dp с увеличением шрифта 140/170%. Нативные скриншоты прикладываются к device-reports в CI.

Проверки с тестовым отправителем и mock-сервером **не означают проверку настоящего банковского аккаунта**. Токены monobank/ПриватБанка и физический телефон пользователя при разработке не используются.
