# OLED 2.2 — что изменено

- Настройки → Плавність · частота екрана → Авто / 60 / 90 / 120. Выбор хранится в DataStore, применяется при смене и при resume. Неподдерживаемые режимы отключены. Авто отдаёт управление Android.
- Добавлены реальные ресурсы cat_neutral, cat_blink, cat_happy, cat_serious, cat_left, cat_right (512×512, lossless WebP, alpha по связанному внешнему чёрному фону). Шаблонная графика больше не является штатным котом.
- Кот дышит, моргает, смотрит на касания в области главного экрана. Баланс ниже нуля выбирает серьёзную позу, положительный — довольную. Это поставляемая 2.5D-анимация; не полноценный поворачиваемый 3D меш.
- Чёрный фон, графитовые карточки без синих поверхностей, зелёные акценты, фиолетовые бары и контекстная подсказка поверх графика. Добавлены подписи оси суммы.
- Добавлены Перекази / Ресторани та кафе / Кешбек, корзина для продуктов, отдельные иконки и оттенки — структура категорий ближе к присланным снимкам. Старые enum names и записи сохраняются, схема таблицы не меняется.
- Верхний кот стал крупнее; текстовый запрос раскрывается кнопкой, чтобы интерфейс не выглядел как постоянная форма.
- Все прежние расчёты, минус в TTS, trial/подписки и редактирование сохранены.

Обновление устанавливать с прежним applicationId и своей подписью, без удаления старой базы. versionCode=4 — рабочий, должен быть больше опубликованного. Приватный ключ не включён; использовать собственный старый ключ.

Зависимости/сборка: JDK 17, Android SDK 36, Gradle/Maven. В данном sandbox нет готового Android toolchain и сети для скачивания, поэтому APK/Android-runtime/120 FPS не проверены. Ресурсная и SQL-проверка не заменяет компилятор.
